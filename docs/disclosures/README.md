# 공시 성장 검증 시범판

시장 화면의 **공시 성장 검증** 링크에서 확인합니다. 5개 종목은 비교용 표본이며 투자 추천이 아닙니다.

- 대상: 코스텍시스, 코리아써키트, 대덕전자, 삼성전자, S-Oil. 추세 통과 여부와 무관하게 수집합니다.
- 입력: OpenDART 전체 재무제표·공시 목록·공시 원문 ZIP. 키는 기존 GitHub Secret `DART_API_KEY`만 사용하고 파일·화면·로그에 내보내지 않습니다.
- 최근 3개 연도를 새로 조회하여 정정 반영 기회를 확보합니다. 과거 150일 경과 캐시 고정은 사용하지 않습니다. 조회 시점의 재작성 수치이므로 과거 투자 시점 백테스트 자료가 아닙니다.
- 분기 손익은 당기 금액, 4분기는 연간에서 9개월 누적을 차감합니다. 현금흐름·유형자산 취득은 누적값에서 직전 누적값을 차감합니다. 연결·별도가 다르거나 직전 값이 없으면 계산하지 않습니다.
- 동일한 순이익 계정이 IS와 CIS에 반복되면 IS를 우선합니다. 같은 명세 안의 모호한 중복은 미확인으로 둡니다. 누락값을 0이나 가점으로 바꾸지 않습니다.
- 연구 조건: 최근 두 분기 매출 전년 대비 각각 10% 이상 증가, 최근 두 분기 영업흑자, 최근 4분기 영업현금·설비취득 차감 현금흐름 양수, 자본 양수. 하나라도 모르면 보류합니다. 재고·채권 증가율이 매출 증가율을 20%p 초과하면 원문 검토로 보류합니다.
- 원문: 사업·반기·분기보고서의 최신/전년 동분기와 주요 자금조달·계약 공시를 최대 8개 읽습니다. 정정 제출은 해당 기간 최신본을 고릅니다. 원문 일부를 키워드와 앞뒤 문맥으로 발췌하고 접수번호·문서 해시·문자 위치를 남깁니다. `requires_review`는 사람이 읽어야 한다는 뜻입니다.
- 전체 문서 해시 변경은 사업 변화의 증거가 아닙니다. 숫자·서식 변경이 포함됩니다. 공시 제목으로 긍정·부정 점수나 수주 확정성을 판정하지 않습니다.
- 실행: `python -m unittest discover -s tests -p test_disclosure_research.py -v`, `python disclosure_research.py`. 기존 성공 자료의 평가만 재생성하려면 `--offline`; 실제 수집 확인일은 갱신하지 않습니다.
- 저장: `docs/data/disclosures/{code,index}.json`, 관측 보존본 `research/disclosures/{code}/{digest}.json`. 오류 난 기업의 이전 파일은 보존하되 새 색인에서 최신 성공으로 표시하지 않습니다.
- 실행 연결: 기존 재무 수집 워크플로가 성공하면 별도 공시 검증 워크플로가 실행됩니다. 수동 실행도 가능합니다. 기존 전략·가상계좌·매매 규칙은 변경하지 않습니다.
- 범위 제한: 12월 결산 비금융기업 시범판입니다. 회계 기준 변경·전년 재작성 비교, 고객 집중·계약 최소구매 의무·기술해자·경쟁 우위·가치평가의 최종 판단은 수동 검토가 필요합니다. 전체 상장사로 확대하기 전 호출량·회계 계정·업종별 예외 검증이 필요합니다.
