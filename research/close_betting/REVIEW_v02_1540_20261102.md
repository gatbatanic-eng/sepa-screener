# 종가 이후 주도주 선별 검토 v0.2
기록일: 2026-11-02 KST
상태: 설계 검토 완료 / 구현·예약·수익성 검증 전
v0.1의 15:20 이전 브리핑안에 대해 사용자가 제시한 시장 판단·2-2-2·재료 검증·전체시장 순위 탐색을 검토한 별도 연구 기록이다. 기존 운영 코드와 Actions는 수정하지 않았다.

## 결론
15:40까지 KRX 15:30 정규장 종가 기준으로 2-2-2와 관찰0순위를 보고하고, NXT 실제 진입 가능 여부는 별도 조건으로 심사하는 구조가 더 적합하다. 다만 15:30부터 전시장 탐색과 원문 검증을 처음 시작하면 10분 내 안정적인 완료는 미검증이며 현실성이 낮다. 장중 사전 탐색과 마감 후 소수후보 갱신이 필요하다. 이는 종가 단일가 참여 전략과 별개의 진입 계열이다.

## 사용자 기준 평가
- 유지: 시장 선행 판단, 약세장 상대강도 확인, 전체시장 조건별 순위 합집합, 700종목 표본으로 제한하지 않기, 각 분류 최대2종목/빈칸 허용, 관찰0순위와 매수가능 후보 구분, 원문 재료 확인, 잠정수급 구분, 임의 점수·승률 금지, 미체결·관망 포함 기록.
- 2-2-2는 탐색·보고 분류이며 매수 할당량이 아니다. 한 종목에 주분류1개와 중복 태그를 붙이고 고유 후보 수를 표시한다. 동일 테마 6개를 서로 독립된 기회로 보지 않는다.
- 시장 판단은 사실과 행동으로 연결한다. 예: 지수 약세여도 후보 지지·VWAP·동반주 강도가 유지되면 검토 유지; 시장 악화와 후보 지지 이탈이 겹치면 보류. 고정 지수하락률 하나로 전부 제외하지 않는다.
- 대장 정의는 해당 테마 내 거래대금 규모, 가격 주도 시점, 동반주 반응 등 근거로 설명한다. 시총·상승률·조회순위 중 하나로 단정하지 않는다.
- 0순위의 '전일'은 보고일 D를 기준으로 D-1이고, 15:40 보고의 중심은 D의 확정 KRX 정규장 가격·거래대금이다. 전일 관심은 연속성의 보조 근거다. 익일 보고에서는 기준일을 다시 지정한다.
- 250거래일 신고가는 고가 기준인지 종가 기준인지 구분하고 수정주가·기업행사 처리를 명시한다. 상장250일 미만은 상장 후 최고가로 표시한다.
- 15분봉120개 평균은 정규장 봉만 쓸지 NXT까지 포함할지 고정해야 한다. 기존 100개5분봉만으로 계산할 수 없다. 여러 거래일 분봉 이력 확보 필요.
- 거래대금 집중구간을 정확한 체결가격별 분포로 해석하려면 틱/가격대별 체결자료가 필요하다. OHLCV만 있으면 근사이며 별도 표시한다.
- 수급의 당일 행 존재는 확정치 증거가 아니다. 프로그램·외국인·기관을 합산하지 않고 데이터의 집계시장·기간·단위·갱신시각을 보존한다.
- 최신 공시 확인에 실패하면 '악재 없음'이 아니라 '미확인'이다. 최종 진입검토에 필요한 위험 검증 실패와 단순 인기순위 누락을 구분한다.

## 시장별 시각
NXT 공식 안내: 애프터마켓 주문접수15:30~20:00, 체결15:40~20:00. 별도 종가매매시장은15:30~16:00 KRX 종가로 매매한다. 양자는 다르다.
- KRX 종가: D 15:30 정규장 마감 가격으로 고정 저장. 공급원에 실제 반영되었는지 확인.
- NXT 애프터: D15:40부터 변동가격으로 거래. KRX 종가에 체결된다는 가정 금지.
- 종가매매: 고정가격이어도 상대주문·수량 부족으로 미체결 가능. 대상 종목과 증권사 제공 경로 확인 필요.
- NXT 당일 대상종목/정지/증권사 지원을 확인한다. 비대상종목은 전체시장 관찰후보에는 남기되 NXT 진입후보에서 분리.
- 15:40 이전 NXT 마지막 체결값을 애프터마켓 최신체결로 부르지 않는다. 호가·예상체결·마지막체결을 구분.
- 15:40 브리핑은 NXT 개장 후 완성분봉을 알 수 없다. 필요하면15:40 이후 별도 재확인; 예를 들어15:45 확인은 잠정안이며 승인된 매수시간으로 취급하지 않는다.
- 특별장/휴장일에는 고정시각을 그대로 적용하지 않는다.

## 권고 처리 흐름
장전: 일봉/종목마스터/실적/이벤트/전일 관심 준비.
14:30~15:20: 코스피·코스닥 거래대금 각50, 상승률 각30, 급증/인기 등 확보 가능한 순위 합집합. 건수·필터·시장·시각·누락 기록. ETF/우선주/스팩 등 분리.
15:00~15:25: 10~15개 정도 정밀조회 및 재료원문 검토(분석 예산 초안, 유력후보 강제탈락 기준 아님).
15:30~15:34: 6개 내외 최종 후보의 KRX 확정종가·마감봉·거래대금 갱신. 종가단일가로 인한 가격/거래대금 변화도 기록.
15:34~15:37: 후보 최신 공시·정정·부인·희석위험 재확인, NXT 대상/호가/예상체결 확인.
15:37~15:39: 결정적 템플릿으로 보고서 생성·전달.
15:40 이전 도착 목표. NXT 진입은 최신 실행가격·스프레드·허용가격·무효화거리 재확인 후 별도 판정.
위 시간은 성능 목표이며 아직 측정된 SLA가 아니다. 기존 cron의 지연 문제는 보고시각을 늦춰도 사라지지 않는다. 데이터 부족 시 보류 보고서를 정시에 낸다.

## 주요 미해결 데이터
1. 전체시장 순위 안정 수집: 기존 On Demand는 개별조회 기능이다. NH 공식 국내주식 문서와 현재 구현에서 필요한 전체 순위를 모두 확보했다는 근거가 없다. 공급원별 실제 목록·분량·페이지·지연 검증 필요.
2. 이번 웹 점검에서 네이버 거래량상위/상승률 기존 URL은 새 페이지로 리다이렉트되어 현재 도구로 목록 취득 실패. 영구적 접근불가로 단정하지 않지만 확보 완료로 기록하지 않는다.
3. NXT 공개 사이트 순위는20분 지연 표기가 있어 발견용과 실행용을 구분해야 한다.
4. NH NXT 시세/호가 채널은 공식 문서에 있으나 현재 사용자 키·수집 코드의 실제 NXT 수신은 이번 점검에서 미검증.
5. 뉴스/테마 매핑·공식원문·공시시간과 경제적 영향은 자동 수치만으로 확정되지 않음. 장중 사전 검토 후 후보 소수에 집중.
6. 환율·해외 선물·예정 정책은 D15:40에 알 수 있는 값만 사용. 전날 미국 종가와 당일 선물의 기준시각을 구별.
7. 장후 거래량·대금과 KRX 정규장 확정값을 혼합하지 않도록 데이터 스키마 분리.

## 판정과 출력
탐색범위·누락 → 시장흐름 → 조건별 발견 → 압축이유 → 2-2-2 → 관찰0순위 → 실행검토 순서 유지.
최종 후보별: KRX 종가, NXT 실제가격/호가와 시각, 재료사실/해석, 강점·약점·미확인, 진입검토/보류/제외, 사유(자료미확보/조건미충족/시장비대상), 허용가격·추격금지·무효화·유효시간, 미체결처리.
사용자 주문금액 미확인 시 유동성은 잠정; 수량 제시하지 않음.
0순위는 전체시장 탐색 충분성에 따라 '확보 후보 내 잠정0순위'로 한정 가능.

## 검증
첫20거래일은 운영/데이터 기간. 보고시간, 원문근거율, 최신성, NXT 대상일치, 재조회 후 판정변경, 미체결과 누락 경로를 기록.
선정성과와 매매규칙 성과와 실제 사용자 실행을 분리한다.
15:20 이전 전략,15:40 NXT전략,종가매매전략은 별도 strategy_id로 기록.15:40 정보로15:30 종가에 확실히 체결했다고 백테스트하면 미래정보/체결편향이다.
NXT 역사적 호가·분봉·대상종목 이력이 부족하면 장후 전략은 전향 모의검증으로 먼저 축적한다. 익일 고가만으로 성공 처리 금지. 보유기간/시간청산/추가매수는 아직 확정하지 않았다.
