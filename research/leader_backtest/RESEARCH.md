### 4.4 대규모 규칙 탐색 (`search_2017_2026/search.md`, 설계 `leader_backtest/search.py` 독스트링, 2026-11-03 고정)
조합 10만 개 x 시장 2개, 훈련 2017~2020 / 검증 2021~2023 / 시험 2024~, 섞은 데이터 귀무 8회, 점수 = min(훈련 t, 검증 t). 유효 조합(구간별 신호 250개·60일 이상): 미국 20,112개, 한국 16,502개.
| | 미국 | 한국 |
|---|---|---|
| 실제 최고 점수 | 2.51 | 3.26 |
| 귀무 8회 최고 점수 | 2.04~2.82 | 1.87~2.49 |
| 점수 99% / 99.9% 분위수 (실제 vs 귀무) | 1.15 vs 1.27 / 1.84 vs 1.81 | 1.87 vs 1.12 / 2.42 vs 1.59 |
| 상위 20개 중 시험 초과수익 양수 | 20/20 | 20/20 |
- 미국: 실제 점수 분포가 귀무와 거의 같다. 최고 점수도 귀무 최고 범위 안이라 우연과 구분되지 않는다. 상위 후보에 ATR>=4%·보유 40~60일이 몰려 있으나 이 데이터 안에서 찾은 패턴이다.
- 한국: 실제 점수 분포가 귀무보다 확실히 위(99% 1.87 vs 1.12)이고 최고 점수 3.26이 귀무 8회 최고(2.49)보다 높다. 시장 필터(100/150/200일선) + 52주 고점 근접 + 50일선 이탈 청산(SMA50X) 또는 짧은 보유+손절 조합이 많다. 다만 8회 복제로는 p<0.05를 증명할 해상도가 안 된다(최소 가능 p 약 0.11).
- **설계 한계(발견)**: Bonferroni p는 귀무 점수 풀(유효 약 13만 개)의 해상도 때문에 0.76 미만으로 내려갈 수 없다. 표의 p=0.76/1.0은 '유의하지 않다'가 아니라 '이 크기의 귀무로는 판정 불가'다.
- 시험 구간 20/20 양수는 증거가 약하다. 유효 조합 전체 평균 초과수익도 시험에서 양수(미국 +0.72%p, 한국 +1.04%p)여서 시험 기간 자체가 신호에 유리했다.
- 신호 단위 평가이고 상위 일부는 신호가 전체 행의 대부분(예: 한국 10만 건)이라 종목 선별보다 시장 필터·청산 효과에 가깝다.
- 판정: 미국은 우연 이상의 후보 없음. 한국은 '있을 수 있으나 미확정'. 다음: 귀무 복제를 40회 이상으로 늘려 같은 설계로 재판정하고, 한국 상위 군집은 포트폴리오 시뮬레이션(ops 방식)으로 재검증.

#### 4.4 갱신: 귀무 40회 재판정 (`search_null40/search.md`, 같은 설계, 복제 횟수만 8->40)
| | 미국 | 한국 |
|---|---|---|
| 유효 조합 | 20,077 | 16,512 |
| 실제 최고 점수 | 2.50 | 3.29 |
| 귀무 40회 최고 점수 (최소/중앙/최대) | 1.77 / 2.37 / 3.09 | 1.84 / 2.16 / 2.73 |
| 현실점검 p (귀무 최고 >= 실제 최고인 비율) | 0.37 | **0.024** (최소 가능값) |
| Bonferroni p (유효 N 기준, 1~2위) | 0.40 / 1.0 | 0.025 / 0.025 (3~5위 0.05) |
- 미국: 실제 최고 점수가 귀무 최고들 안쪽(40회 중 15회가 실제 이상) -> 우연과 구분되지 않는다. 후보 없음.
- 한국: 실제 최고 점수 3.29가 귀무 40회 최고 점수 전부(최대 2.73)보다 높다. 5% 수준에서 우연으로 설명하기 어렵다(현실점검 p=0.024, Bonferroni 유효 N 기준 0.025~0.05). 단, 10만 개 N 기준 Bonferroni는 0.15 이상이라 '조합 수를 전부 센다'면 확정은 아니다.
- 한국 1~5위는 짧은 보유(10일) + 손절 6~8% + 시장 필터(150/200일선) + 거래량 증가 + ATR 2~3% 이상 계열. 신호 단위 시험 초과수익은 +0.4~+1.4%p(10일 보유 기준)로 작고, 1~2위는 시험 t가 1.3~1.4로 약하다.
- 한계: 실제 거래에서는 거래량 급증·변동성 큰 종목에서 슬리피지가 이 폭(0.4~1.4%p)을 잠식할 수 있다. 포트폴리오 시뮬레이터가 고정 보유 청산을 지원하지 않아 이 계열은 아직 포트폴리오 검증 전이다(4.5는 SMA50X 계열만).
- 재실행 시 데이터가 하루 늘어 점수가 소폭 달라졌다(미국 2.51->2.50, 한국 3.26->3.29). 결론은 같다.
