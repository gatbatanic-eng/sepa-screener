# Golden Code 전략 라이브러리 규격 v1.3

작성일: 2026-10-07 (v1.0) · 개정: 2026-10-08 (v1.3, 변경 이력은 문서 끝)

## 개요

Golden Code가 고른 종목을 "어떤 방식으로 사야 기대값이 높은가"까지 데이터로 답하기 위한 전략 라이브러리의 첫 규격이다. 목표는 예측이 아니라 기대값 추정과 리스크 관리이며, 모든 결과는 라이브 추적(R7/R30/R60/R90)으로 승격되기 전까지 가설로 취급한다.

**설계 원칙**

- 변인은 늘리지 않고 소수의 국면 축으로 압축한다.
- 정량 시스템은 기본값을 제시하고, 이벤트와 정성 판단은 사람이 얹는다.
- 파라미터는 P1에서 최적화하지 않고 고정한다. P2에서 ±20% 민감도만 본다.
- 각 규칙에 출처 수준을 표기해 원전과 변형을 구분한다.

**레이어 구조**

1. L1 데이터: 가격·거래량, 매크로 지표, 이벤트 캘린더
2. L2 국면 분류: 지수 추세(200일선 또는 10개월선) × 변동성(VIX 백분위) 2×2 + 이벤트 플래그
3. L3 전략 라이브러리: 이 문서의 대상
4. L4 검증 엔진: 비용 반영, Walk-forward, 랜덤 베이스라인, 최소 표본
5. L5 Decision Layer 연결: 보조 점수, 리스크 가이드, 이벤트 경고. 최종 판단은 사람
6. 라이브 추적: R7/R30/R60/R90 성과를 전략·국면별로 피드백

**유니버스 결정 (A안, v1.1·v1.2 개정)**: P1은 **S&P500 현재 구성종목 전체**(FinanceDataReader `StockListing("S&P500")`)로 시작한다. 수집 시점의 구성종목을 과거 전 구간에 적용하므로 편출·상장폐지 종목이 빠져 있다(생존편향). 데이터 품질 사유로 일부 종목은 P1 유니버스에서 제외한다(아래 '데이터 처리 규칙', `config/universe.yaml`의 `exclude`). 생존편향으로 성과가 부풀려진다고 전제하고, P1 결과는 파이프라인 동작 확인용으로만 쓴다. P2부터 규칙 기반 동적 유니버스나 Golden Code 선정 이력으로 교체해 재검증한다.

## 전략 선정 근거

학계, 실계좌 투자대회, 기관 운용이 모두 "강한 종목의 고점 돌파 + 손실 제한"을 가리킨다. 이 수렴을 근거로 돌파 계열을 핵심에 두고, 평균회귀는 대조군으로만 둔다.

| 근거 유형 | 대표 사례 | 가리키는 것 |
| --- | --- | --- |
| 학술 논문 | 사상 최고가 추세추종(Wilcox & Crittenden 2005, 2025 재검증), 52주 고점(George & Hwang 2004), 12-1 모멘텀(Jegadeesh & Titman 1993/2001) | 모멘텀, 고점 근접, 돌파 |
| 미국 실계좌 대회 | US Investing Championship: 미너비니 1997·2021 우승, 상위권 다수가 그의 수강생 | 주도주 신고가 돌파 + 타이트한 손절 |
| 독립 기계적 추적 | AAII CAN SLIM 스크린(1998년\~) | 성장 + 상대강도 |
| 한국 실전투자대회 | 신고가·박스권 돌파, 주도 테마 | 돌파, 주도주 |
| 기관 | AQR 등 모멘텀 팩터, CTA 추세추종 | 모멘텀, 추세 |

**제외한 것과 이유**

- 20EMA 눌림목, 일봉 변동성 돌파, NNFX: 독립적인 체계적 검증 연구를 찾지 못함
- 실적 발표 후 드리프트(PEAD): 2006년 이후 소멸했다는 연구가 있음
- 한국 대회 기법: 참가자 평균 성과 비공개, 대부분 코드화 불가

**공개 후 성과 감소 전제**: 논문 공개 이후 이상수익은 평균 절반 수준으로 줄어든다(McLean & Pontiff 2016). 논문 수치는 상한선으로 본다.

**라이브러리 구성**

| 구분 | 코드 | 전략 | 역할 |
| --- | --- | --- | --- |
| 검증군 | A1 | 사상 최고가 돌파 + ATR 트레일링 | 핵심 진입 전략 |
| 검증군 | A2 | Connors RSI(2) 평균회귀 | 대조군 |
| 실험군 | B1 | 터틀 System 2 (55일 돌파) | 주식 적용 검증 |
| 실험군 | B2 | SEPA 근사 | 대회 검증 방법론의 기계화 |
| 실험군 | B3 | 쿨라매기 브레이크아웃 근사 | 단기 모멘텀 셋업 |
| 선별 레이어 | S1 | 12-1 모멘텀, CAN SLIM 스크린 | Golden Code 선정과 비교 |
| 국면 필터 | R1 | 지수 10개월선 (시계열 모멘텀) | L2 국면 |

실험군은 백테스트 성과가 좋아도 라이브 추적에서 살아남기 전까지 Decision Layer 점수에 반영하지 않는다.

## 공통 규격

모든 전략은 아래 규격을 따르며, 진입 방식만 전략별로 M1 또는 M2를 쓴다.

**출처 표기**: \[원전\] 출처 규칙 그대로 · \[근사\] 일봉 구현을 위해 바꾼 것 · \[임의\] 원전에 없어 정한 값 · \[관례\] 커뮤니티 통용값

| 진입 모델 | 방식 | 적용 |
| --- | --- | --- |
| M1 종가 확인형 | 종가로 신호 판정, 다음날 시가 체결 | A1, A2, B2 |
| M2 스탑주문형 | 전날 정한 돌파가에 매수 스탑, 당일 고가가 닿으면 max(시가, 돌파가) 체결 | B1, B3 |

| 항목 | 규칙 |
| --- | --- |
| 데이터 | 일봉. 지표·신호는 **완전 수정 OHLC**(공급자 OHLC × Adj Close/Close)로 계산한다. 비수정 종가는 분할 이벤트로 역산해 10달러 필터에만 쓴다. 수정·비수정 처리는 data 계층에서 한 번만 한다 (아래 '데이터 처리 규칙') |
| 방향 | 롱 온리 |
| 비용 | 편도 수수료 0.05% + 슬리피지 0.05% (중소형 고변동 종목 편입 시 0.10\~0.15%) |
| 포지션 | 종목당 1포지션, 피라미딩 없음. 부분청산은 B3만 허용 |
| 손절 종류 (v1.3) | 모든 손절·청산 의도에 `kind = intraday \| close`를 둔다(진입 모델과 무관). **intraday**: 시가 ≤ 손절가면 시가 체결, 아니면 저가 ≤ 손절가일 때 손절가 체결. 진입 당일에도 적용한다(M1은 시가 진입 후, M2는 돌파가 진입 후). **close**: 종가 < 손절가면 다음날 시가 체결. 진입 당일 장중 저가로는 손절하지 않고 진입 당일 종가부터 판정한다 |
| 동시 발생 (v1.3) | M2 진입 당일 intraday 손절은 손절가 체결로 고정한다. M2는 장중에 진입하므로 진입 전 시가는 이후 손절 체결가와 무관하다(시가가 손절가 아래여도 같다). 같은 날 처리 순서는 시가 체결 청산 → 시가 갭 및 장중 손절 → 종가 청산이다. 일봉으로 순서를 알 수 없는 경우는 보수적으로(손절 우선) 처리한다 |
| 1R · R-multiple (v1.3) | 1R = 진입가 − 초기 손절가(비용을 뺀 체결가 기준). r_multiple = (청산가 − 진입가 − 진입비용 − 청산비용) / 1R. 비용 = 체결가 × (수수료 + 슬리피지), 진입·청산 각각 적용. 분할 청산은 트랜치 가중 합산 |
| 데이터 끝 미청산 (v1.3) | 확정 거래 통계와 마지막 종가로 평가한 통계를 둘 다 산출한다. 미청산 포지션은 마지막 종가에 청산한 것으로 보고(청산 비용 포함) `exit_reason = open_mtm`으로 표시한다 |
| 평가 단위 | P1은 포트폴리오 시뮬레이션 없이 거래 단위 R-multiple 분포 |
| 파라미터 | 고정. P2에서 ±20% 민감도, 성과가 좁은 한 점에만 있으면 탈락 |
| 기간 | 2015년\~현재, 지표 워밍업용 데이터는 그 이전부터 |

## 검증군

A1은 손절 공식 확인 전까지 구현 보류, A2는 바로 구현 가능하다.

### A1. 사상 최고가 돌파 + ATR 트레일링

출처: Wilcox & Crittenden(2005), Zarattini·Pagani·Wilcox(2025, [SSRN 5084316](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5084316)). 1950\~2024년 생존편향 제거 데이터, 6만6천 건 이상 거래로 재검증.

- 유동성 필터 \[원전\]: 수정 전 종가 > 10달러, 42거래일 평균 거래대금 > 100만 달러
- 진입 \[원전, M1\]: 수정종가 ≥ 사상 최고가 → 다음날 시가 매수
- 청산 \[원전\]: 종가 < 손절선 → 다음날 시가 매도 (손절 종류 **close**, 초기·트레일링 모두)
- 손절선 \[원전\]: max(직전 손절선, f(사상 최고가, ATR42)). 내리지 않음
- 미확정: f의 정확한 배수. 원 논문 확인 필요. 대안은 2005년판 10 ATR 트레일링을 "A1-2005"로 먼저 구현
- 데이터 주의: 사상 최고가 계산에 상장일부터 전체 이력 필요
- A1 판정 불가 기준 [임의, v1.2]: 종목의 첫 봉이 수집 하한(1970-01-05)이고, 2014-12-31까지 데이터의 최고가(수정종가)가 데이터 첫 252봉 안에 있으면 그 종목은 하한 이전 이력이 잘렸을 수 있어 A1 판정 불가로 표시한다. 첫 봉이 하한이 아니면(상장일부터 이력이 있으면) 상장 직후 최고가여도 정상 처리한다. 2014-12-31 이후 상장 종목도 이 검사 대상이 아니다
- 기대 프로필: 낮은 승률, 거래 7% 미만이 수익 대부분을 만드는 우측 꼬리 분포. 이론 CAGR 15.02%, MDD 31.75%(논문, 회전율·비용이 실전 난관)

### A2. Connors RSI(2) 평균회귀

출처: Connors & Alvarez, *Short Term Trading Strategies That Work*(2008). 실무 백테스트 수준의 근거.

- 진입 조건 \[원전\]: 종가 > 200일선, 종가 < 5일선, RSI(2) < 10
- 체결 \[근사, M1\]: 원전은 종가 진입, 여기선 다음날 시가
- 청산 \[원전\]: 종가 > 5일선 → 다음날 시가 (**close**)
- 손절: 두 버전 병행
  - A2-원전: 손절 없음. R 계산용 명목 리스크만 3×ATR(14) \[임의\]
  - A2-안전판: 3×ATR(14) 실제 손절 \[임의\] (**intraday**)
- 두 버전의 차이로 "손절이 평균회귀 전략을 해치는가"를 판정한다.

## 실험군

세 전략 모두 바로 구현 가능하다. B2의 베이스·수축 조건과 B3의 조정 조건은 \[임의\] 비중이 커서 사용자 검토가 필요하다.

### B1. 터틀 System 2

출처: Richard Dennis의 터틀 규칙(원래 선물용).

- N \[원전\]: 20일 ATR
- 진입 \[원전, M2\]: 직전 55일 최고가에 매수 스탑
- 초기 손절 \[원전\]: 진입가 − 2N, 장중 스탑 (**intraday**)
- 청산 \[원전\]: 직전 20일 최저가 이탈, 장중 스탑 (**intraday**)
- 제외 \[단순화\]: ½N마다 최대 4유닛 피라미딩(v2), 숏
- 목적: "55일 돌파가 주식에서도 통하는가"를 A1과 비교

### B2. SEPA 근사

출처: Mark Minervini, *Trade Like a Stock Market Wizard*. 원전 확인 권장.

**트렌드 템플릿 \[원전, 8개 조건\]**

1. 종가 > 150일선, 200일선
2. 150일선 > 200일선
3. 200일선이 22거래일 이상 우상향
4. 50일선 > 150일선, 200일선
5. 종가 > 50일선
6. 종가 ≥ 52주 저점 × 1.30
7. 종가 ≥ 52주 고점 × 0.75
8. RS ≥ 70 \[근사\]: IBD 전체 시장 순위 대신 S&P500 대비 12개월 상대수익률 백분위

**베이스·수축(VCP) 근사 \[임의\]**

- 베이스 기간 20\~60일, 깊이(고점 대비 저점) ≤ 25%
- 최근 10일 변동폭 ≤ 베이스 깊이의 50%
- 10일 평균 거래량 < 50일 평균 거래량
- 피벗 = 베이스 내 최고가

**매매 규칙**

- 진입 \[근사, M1\]: 종가 > 피벗 + 거래량 ≥ 50일 평균 × 1.4 → 다음날 시가. 거래량 조건이 장 마감 후 확정되므로 장중 돌파 대신 종가 확인형
- 초기 손절 \[원전 원칙 + 근사\]: 진입가 × 0.92와 최근 10일 저점 중 가까운 쪽 (**intraday**)
- 청산 \[근사/임의\]: 종가 < 50일선, 또는 +2R 이후 10일 저점 이탈 (**close**)

### B3. 쿨라매기 브레이크아웃 근사

출처: Kristjan Kullamägi의 공개 인터뷰·스트림. 계좌 성과는 본인 공개 기반.

- 사전 상승 \[원전\]: 종가 ≥ 최근 63거래일 최저 종가 × 1.30
- 변동성 필터 \[관례\]: ADR(20) ≥ 4%
- 정돈된 조정 \[근사\]: 최근 10\~40일 횡보, 최근 5일 저점 > 그 이전 10일 저점, 종가 > 20일선, 10일선 > 20일선
- 진입 \[근사, M2\]: 횡보 구간 고점에 매수 스탑. 원전의 시가 범위 고점 돌파는 분봉이 필요해 일봉 근사
- 초기 손절 \[원전\]: 진입일 저가. 진입가 − 저가 > 1×ATR(14)이면 진입가 − ATR (**intraday**. 진입일 저가는 진입일 장 마감 후 확정되므로 진입 다음 봉부터 유효하다)
- 부분청산 \[원전, 2트랜치\]:
  - 트랜치 A 50%: 진입 후 5거래일째 종가에 청산 (일정이 미리 정해진 종가 청산, 손절 아님)
  - 트랜치 B 50%: 5일 경과 후 손절을 본전으로(**intraday**), 종가 < 10일선이면 청산(**close**, 20일선은 민감도 테스트)
- R-multiple은 두 트랜치 합산

| ticker, strategy, version | 종목, 전략 코드(A1\~B3), 규격 버전 |
| signal\_date, entry\_date, entry\_price | 신호일, 체결일, 체결가 |
| initial\_stop, exit\_date, exit\_price | 초기 손절가, 청산일, 청산가 |
| exit\_reason | stop / trailing / time / rule / partial |
| tranche | 부분청산 전략(B3)의 트랜치 구분 |
| hold\_days, costs | 보유일수, 수수료·슬리피지 합계 |
| r\_multiple, mfe\_r, mae\_r | 비용 후 R, 최대 유리·불리 변동(R 단위) |
| regime\_tag, event\_flag | 신호 시점 국면 태그, 이벤트 구간 여부 (P3 대비) |

**검증 지표**

- 거래 수, 승률, 평균 R, 기대값(R), 비용 후 PF, 거래 순차 누적 MDD, 최대 연속 손실
- Buy & Hold 대비 (같은 종목·기간)
- 랜덤 진입 대비: 같은 보유기간 분포로 1000회 반복한 분포에서의 백분위
- 전략 간 신호 중복도: A1·B1·B2·B3는 모두 돌파 계열이라 같은 종목·같은 주에 겹치는 비율 측정
- 최소 표본: 집계 셀당 30거래 미만은 "판정 불가"

**승격 단계**

1. 백테스트 통과: 비용 후 기대값 > 0, 랜덤 대비 상위 5%, 민감도 테스트 통과
2. Walk-forward 통과: 앞 구간 선별, 뒤 구간에서 유지
3. 라이브 추적: 신호를 R7/R30/R60/R90으로 기록, 일정 건수 이상 백테스트 분포 안에서 유지
4. 점수 반영: 검증군은 2단계 후, 실험군은 3단계 후 Decision Layer 보조 점수에 반영

라이브 성과가 백테스트 분포에서 크게 벗어나면 "전략 이상 징후"로 표시하고 가중치를 낮춘다.

**데이터 처리 규칙 (v1.2)**

| 항목 | 규칙 |
| --- | --- |
| 데이터 출처 | **가격·지수는 FinanceDataReader(FDR), 분할 이벤트만 yfinance**(`Ticker.splits`, Yahoo 기록. FDR은 분할 이벤트를 주지 않는다). 이벤트 캘린더(실적·FOMC·CPI)는 P3로 미룬다 |
| 완전 수정 OHLC | 공급자 `Close`는 분할만, `Adj Close`는 분할+배당을 보정한다. Open·High·Low에 `Adj Close / Close` 비율을 곱해 완전 수정 OHLC를 만든다. 이 처리는 data 계층에서 한 번만 하고, 이후 코드는 다시 보정하지 않는다 |
| 비수정 종가 | `Close × (해당 날짜 이후 분할 비율의 곱)`으로 역산한다(분할일 당일 봉은 이미 분할 후 가격). 분할 조회가 실패한 종목은 비수정 종가를 비워 두며 분할이 없다고 가정하지 않는다 |
| 10달러 필터 | 비수정 종가에만 적용한다. 거래대금은 `Close × Volume`(분할에 불변)으로 계산한다 |
| 마지막 봉 | 장 마감이 확인된 봉만 쓴다(미국 16:10 ET 이전의 당일 봉은 버린다) |
| 결측·이상치 | 채우지 않고 기록한다. 가격이 비었거나 0 이하인 행은 제거하고 날짜를 manifest에 남긴다. 2014-01-01 이후 거래량 0, NaN, 일간 ±40% 이상 등락을 집계하고, 사상 최고가를 새로 만든 이상치 봉은 따로 표시한다 |
| 이력 한계 | 수집 시작일은 1970-01-05다(FDR이 Windows에서 1970년 이전 날짜를 못 받는다). 그 이전 이력은 풀지 않는다 |
| 시작 구간 절단 [임의] | 종목 시작 구간에서 O=H=L=C이고 거래량 0인 봉이 5개 이상 연속이면 그 연속 구간 끝까지 자른다(공급자가 상장 전·미국 상장 전을 멈춘 가격으로 채운 구간). 시작 구간만 대상이고 중간의 정지 봉은 건드리지 않는다. 잘린 종목과 구간은 manifest에 기록한다 |
| 보정 오류 탐지 (v1.3 교체) | **DHR형**: \|수정 수익률\| − \|공급자 Close 수익률\| > 10%p 이고 \|수정 수익률\| > 15%인 봉(수정 종가가 공급자 Close보다 크게 튀는 봉)을 종목·날짜·두 수익률·분할 이벤트 여부(ex-date ±3 달력일)와 함께 `quality_report.json`에 목록화한다. 수정이 매끄럽고 공급자 Close가 크게 떨어지는 봉은 특별배당·분리상장이 제대로 보정된 것이라 걸리지 않는다. 두 수익률 차이가 10%p를 넘는 봉 전체(특별배당·분리상장 포함)도 정보용으로 함께 남긴다 |
| P1 유니버스 제외 [임의, v1.3] | 데이터는 보관하되 `manifest/universe_p1.json`에서 뺀다: (1) 정적: DHR(분리상장 보정 오류), CTVA(분리상장 미보정), SW·FERG·AMCR(미국 상장 이전 정지 봉이 수년간 산재) (2) 2014-01-01 이후 DHR형 보정 오류 봉이 있는 종목 (3) 2015-01-01 이후 시작하는 5봉 넘는 연속 결측(가격 NaN·0 이하)이 있는 종목. 사유는 `config/universe.yaml`에 둔다 |
| 수동 검토 목록 | CTVA형(공급자·수정 수익률이 같이 크게 움직이는 봉)은 자동 탐지가 안 되므로 2014-01-01 이후 일간 ±40% 봉 전체를 `manifest/review_big_moves.json`에 거래량 배수·신고가 여부와 함께 남기고 사람이 검토한다 |
| 캐시 보호 | 재수집 결과가 기존 캐시보다 행이 적거나, 과거 구간의 비수정 종가·수정 종가 일간 수익률이 바뀌었으면 덮어쓰지 않고 경고 후 기존 캐시를 유지한다. 수집이 실패해도 기존 캐시가 있으면 그것을 쓴다. 내역은 manifest의 `cache_changes`에 남는다(새 배당·분할로 수정 종가의 절대 수준이 바뀌는 것은 정상이라 비교하지 않는다) |
| 보관 | `golden_backtest/data_cache/`(parquet, git 제외). 수집 기록(수집일, 종목 수, 종목별 행 수·첫 봉·마지막 봉)은 `golden_backtest/manifest/`에 JSON으로 커밋한다 |
