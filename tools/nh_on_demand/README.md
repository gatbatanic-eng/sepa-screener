# NH Stock On Demand

기존 저장소의 `NHPLUG_APPKEY`, `NHPLUG_APPSECRET`로 한 종목을 일회성 조회한다.
별도 키 등록이나 나무 앱 설치가 필요하지 않다. 기존 스크리너의 계산·저장 파일과 분리된다.

## 실행

[Actions 실행 화면](https://github.com/gatbatanic-eng/sepa-screener/actions/workflows/nh-on-demand.yml)에서
Run workflow → master → 종목코드(예: 005930), 시장(KOSPI/KOSDAQ) → Run workflow.
완료된 실행의 Summary에서 조회 시각을 확인한다. Artifacts의 `nh-stock-…` 압축을 풀면
`chart.html`(차트), `snapshot.json`(분석 데이터), `summary.md`가 있다.
현재 채팅 커넥터에는 workflow_dispatch가 없어 최초 실행 버튼은 사용자가 누른다.

## 범위

- KRX 현재가, 최대 400개 일봉, 일봉을 집계한 주봉·월봉, 수급 원자료.
- 이동평균 5/20/60/120, Wilder RSI14, MACD 12/26/9, 볼린저밴드 20·2σ.
- 최근 최대100개 캔들을 HTML로 표시한다. JSON은 전체 수신 봉과 봉별 지표를 담는다.
- 장중 마지막 봉은 미확정. 첫/마지막 주·월봉은 부분 구간일 수 있다.
  월봉처럼 기간이 부족하면 지표를 추정하지 않고 null/기간 부족으로 표시한다.
- 현재가 수신 시각과 공급원 날짜/시각을 분리한다. 거래일 없는 현재가는 최신성 미검증.
  현재가로 일봉을 덮어쓰지 않는다. 휴장일 달력과 수정주가 여부는 미검증이다.
- 수급은 단위·잠정/확정 구분 검증 전 원래 필드로만 표시한다.
- 중복 날짜, 비정상 OHLCV, 빈 가격은 실패 처리. 실패 실행에서 과거 결과를 재사용하지 않는다.

## 인증과 운영 영향

토큰은 실행 메모리에서만 사용하고 폐기 API는 호출하지 않는다. 토큰이나 키를 로그·아티팩트에
기록하지 않는다. 토큰 1회 발급 뒤 현재가/일봉/수급 각1회 요청(일시 오류 시 제한적 재시도).
허용된 세 종류 조회 외 계좌·주문 경로는 차단한다. 수동 실행만 가능하며 정기 예약은 없다.
같은 수동 작업끼리는 순차 실행하지만 기존 수집 작업과 공통 잠금을 걸지는 않는다.
동일 키의 토큰 정책·합산 호출 한도에 따른 충돌 가능성은 장중 실증 전이다.
기존 실행을 취소하거나 토큰을 강제 폐기하지 않는다.

저장소는 공개이므로 Actions 로그/요약에도 비밀 정보나 개인 보유 정보를 적지 않는다.
산출물은 공개 시장 데이터만 포함하고 7일 아티팩트로 보관한다. 코드 외 데이터는 Git에 커밋하지 않는다.
